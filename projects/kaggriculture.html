Abstract

Kaggriculture is a two-player, long-horizon farming economy with simultaneous unit actions, production chains, market interaction, hidden shop variation, and approximately 719 decisions per complete game. A strong script can execute one coherent plan, but a learned agent must adapt when an opponent or earlier mistake changes the state. This project builds a traceable learning stack: complete teacher trajectories, chronological recurrent training, portable inference, fresh-seed evaluation, replay audits, and a reverse curriculum in which a teacher supplies a valid prefix and the learner controls the remaining suffix to the true terminal reward.

1. Why the task is difficult

Actions have delayed and coupled effects. Buying land is useful only if labor, seed, processing, transport, and market demand complete the chain before day 29. The opponent changes prices and accessible states. A locally legal action can make a later plan impossible, while an apparently idle action can preserve cash or synchronize workers for a high-value chain.

Ordinary action classification ignores these consequences. A recurrent learner must infer a latent economic plan while remaining robust when the observed state diverges from the teacher’s nominal route.

2. Building a trustworthy teacher corpus

Two scripted strategies, Pipe7 and V47, were run across seeds, seats, and opponents. Conversion preserves full chronological trajectories rather than shuffling independent states. Each episode records the source hash, engine version, opponent, terminal cash, requested-action support by phase, replay hash, unit width, and market width.

Later-phase training reconstructs the recurrent prefix before computing the sampled loss. This prevents a hidden-state mismatch in which a model is asked to predict day-20 actions from an RNN state that never experienced days 0–19.

3. Learning system

Full-action recurrent imitation

The policy predicts the official action space from public state, private inventory, units, market, shop state, time, and recurrent context. Training mixes teacher sources and complete episodes. Export parity verifies that portable NumPy inference agrees with the training implementation before evaluation.

DAgger, with coherent teacher state

A naive DAgger implementation queried Pipe7 after the learner created an off-route state. That is invalid if Pipe7’s hidden fields—route, pending actions, and sell state—do not match the new world. A deterministic teacher is deterministic only when its observation and internal controller state are coherent. Recovery labels therefore require validated teacher snapshots or fresh continuation rollouts.

4. Evaluation is a replay audit

A fixed checkpoint was tested on 16 unseen seeds, both seats, and three opponents for 96 games. The first aggregate looked better than reality because the official interpreter marked final status as DONE even when an earlier agent error occurred. A second evaluator inspected every status and verified that the learner was called for every decision.

5. What the audit revealed

A capacity bug looked like strategic failure

All 30 error games exceeded 16 active units immediately before failure. The policy representation supported 16, while the official environment permitted larger workforces. Clipping would hide the cause, so the input contract must expand and the affected games remain invalid.

Training distribution dictated the opponent distribution

The model trained on two Pipe7-versus-wheat games and won most valid fresh games against wheat, yet failed against Pipe7 and V47. In one audited seed, the first divergence occurred at decision 34 while private state was still identical. The model proposed fertilizer sale while Pipe7 waited, built a pasture, and bought wheat. This is direct evidence that opponent-induced states were absent from training.

Action matching was confused with strategy learning

Rewarding an exact Pipe7 action merely converts imitation loss into an RL-shaped number. It cannot reward a different action that yields a stronger terminal economy, and it inherits Pipe7’s hidden-state problem.

6. Teacher-prefix, learner-suffix reinforcement learning

The proposed curriculum preserves coherent state while giving the learner real consequences:

  1. Select seed, seat, opponent, teacher variant, and takeover boundary.
  2. Replay the teacher from turn zero to that boundary, including all market and opponent interactions.
  3. Transfer control permanently to the learner.
  4. Run to termination; the teacher never resumes after the learner changes the world.
  5. Run a paired teacher control game with the same seed, seat, and opponent.
  6. Train from terminal return relative to the paired continuation, with legality and potential-based shaping as auxiliary feedback.

The boundary moves backward: terminal conversion on days 27–29, late investment, established-farm operation, shop adaptation, opening strategy, then the full 719-decision game. Each stage has paired-return and completion gates. Successful learner prefixes enter the replay mixture so the policy can eventually exceed rather than imitate the scripted teacher.

Central finding. The next useful RL experiment is not “run PPO on the current policy.” It is to construct valid suffix episodes on a transition system whose replay, hidden teacher state, input widths, and terminal accounting are already trusted.
